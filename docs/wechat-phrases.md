# 微信日常短语速查（你自己看，不用发给 WorkBuddy）

设计原则：**微信里打字越少越好**。你只发「标签 + 最少必要信息 + 图」，剩下的解释工作全交给 WorkBuddy。
标签语法已在初始化提示词里定义好了，所以它看到标签就知道该干什么。

## 日常录入

| 场景 | 你在微信里发什么 | 备注 |
|---|---|---|
| 睡眠截图 | `[睡眠]` + 截图 | **务必点「原图」发送**，压缩后数字会糊，OCR 容易错 |
| 早餐 | `[饮食] 早餐 08:30` + 照片 | 时间不确定就只写 `[饮食] 早餐` |
| 午餐/晚餐/加餐 | `[饮食] 午餐` + 照片 | 同上 |
| 训练 | `[训练] 卧推 60kg 8x3, 飞鸟 12kg 10x3` + 可选视频 | 数字比视频重要得多 |
| 体重 | `[体重] 78.1` | 晨起空腹、如厕后测，每周至少 1 次 |
| 工作 | `[工作] 专注5h 打断6次` | 没有就不发，别硬凑 |
| 家庭/心情 | `[家庭] 今天陪爸妈吃了饭` | 自由文本，想到才发 |

## 要报告

| 你要什么 | 发什么 |
|---|---|
| 今日日报 | `[日报]` |
| 本周周报 + 建议 | `[周报]` |
| 到期建议回填 | `[回填]` |
| 看看趋势 | `[趋势] 近30天` |

## 三个必须知道的操作细节

1. **图片发原图。** 微信默认压缩，睡眠截图上的小字被压缩后识别准确率会明显下降。
2. **标签放最前面。** WorkBuddy 靠开头的方括号判断动作类型，放后面也可能识别，但放前面最稳。
3. **不用写日期。** 没写就默认是今天。跨天补录才需要写，例如 `[体重] 78.1 2026-10-09`。

## 如果 WorkBuddy 写错了文件

直接发：`[修正] 今天午餐是 650kcal 不是 900`
它会改对应的 md 并把该条置信度标为 `corrected`。

## 双端分工建议（避免两套系统打架）

数据源只有一份，就是 `<你的账本目录>\data\`。
建议：**日常录入归 WorkBuddy（微信方便），周报和深度复盘归你决定用哪边。**
但 `reviews\advice-ledger.md` 只有一份，谁提建议都写进去，不要各记各的。
