## 一、动作技术要点与常见错误

### 卧推（杠铃）

**要点**

- 五点接触：头、肩背、臀贴凳，双脚全掌踩实地面
- 肩胛后缩下沉并全程保持（「把肩胛骨塞进后裤兜」），形成稳定支点
- 握距略宽于肩，杠落在**乳线/胸骨下段**，不是喉咙也不是肚子
- 杠的路径是**斜线**：从锁骨上方出杠 → 落到胸 → 推起回到肩上方，不是垂直上下
- 前臂在底部保持垂直；手腕不过度背伸（杠压在掌根，与前臂同一直线）
- 腿驱动：脚往下踩，把身体往头侧顶，保持肩背压紧
- 离心 2-3 s 控制，胸触杠后不停顿反弹（除非是刻意练停顿卧推）

**常见错误**

| 错误 | 后果 | 纠正 |
|---|---|---|
| 肩胛不收、肩膀前送 | 肩峰下撞击、肩痛 | 强化肩胛后缩下沉，降低重量重建 |
| 杠落太高（靠喉咙） | 肩关节压力剧增 | 落点下移到乳线 |
| 手肘外展 90° | 肩前侧负荷过大 | 肘部收至躯干 45-60° |
| 手腕过度背伸 | 腕关节劳损 | 杠压掌根，必要时护腕 |
| 臀部离凳 | 借力、腰椎超伸 | 减重，练腿驱动 |
| 不扣卡箍（无补手时） | 失败无法卸片 | 无补手时反而**建议不扣卡箍** |

### 引体向上

- 起始悬挂时肩胛**主动下沉**（不是耸肩），避免肩峰撞击
- 拉起时先沉肩胛再屈肘，胸口向杠靠
- 握距略宽于肩，正握/对握均可，避免颈后引体
- 下放到手臂完全伸直（肩胛充分上回旋）
- 常见错误：用身体摆动甩上去（惯性代偿）、半程、耸肩启动

### 高位下拉

- 握距略宽于肩，躯干后仰 **≤15°**
- 拉到**上胸/锁骨**位置，不是颈后（颈后下拉对肩关节风险高）
- 离心控制回到完全伸展
- 常见错误：全身后仰借力、拉到颈后、过快弹震

### 划船类

**杠铃划船**：髋屈约 45°，脊柱中立，杠沿大腿拉向下腹，肘贴身往后带，顶峰 squeeze 但不后仰。

**海豹划船（seal row）**：趴在上斜凳上，胸口悬空。优点是腰椎被凳子锁死，**无法用腰借力**——对背阔是更纯的刺激。

- 凳高调到趴下后手臂能完全伸直、胸口不贴凳
- 拉起时肘贴身后带，顶峰停 1 s，**不要后仰借腰**（趴姿下后仰无效且会伤腰）
- 下放充分送肩胛前伸到底，不要只放手肘
- 常见错误：用腰挺起来、半程、握距过宽导致肩后束代偿

**坐姿绳索划船**：躯干不要前后大幅摆动，靠背阔收缩。

### 深蹲

- 站位略宽于髋，脚尖外展 15-30°
- 全程脊柱中立，核心 360° 撑住（瓦式呼吸）
- 下蹲时**膝与脚尖同方向**，不内扣
- 深度至少大腿平行地面（有条件更深）；不牺牲脊柱换深度
- 站起时先「顶髋」与伸膝同步，避免臀部先抬（变成早安式）
- 常见错误：膝内扣（臀中肌不足）、腰椎反弓/圆背（核心失守）、脚跟离地（踝活动度不足）

### 硬拉

- 起始：杠在足中上方，胫骨距杠约 2-3 cm
- 屈髋屈膝下握杠，手臂垂直、腋窝在杠正上方
- 拉起前**先绷紧**：挺胸、背阔收紧（「把杠掰弯」的意向）
- 杠贴腿垂直上行，髋膝同步伸展（不要先伸膝变成两段）
- 锁定：肩胛后缩，髋完全伸展，不后仰超伸
- 放下：先屈髋后屈膝，控制下放
- 常见错误：起始位置太远（杠在脚尖前）、圆背启动、杠离身体太远（力臂变长）

### 实力推 / 肩推

- 站姿，核心收紧，肋骨下沉（避免腰椎超伸代偿）
- 杠从锁骨出发，头在杠到位后前送让杠过脸
- 顶端肩胛上回旋、耳朵在肱二头肌旁
- 常见错误：腰椎超伸借力、杠走弧线太靠前

### 手臂与腹

- 二头弯举：肘固定，不要摆动上身
- 三头下压：肘贴身，不要外翻
- 卷腹类：用腹部卷起（胸廓向骨盆靠），不是靠髋屈肌拉头
- 悬垂举腿：控制骨盆后倾，避免摆动

## 二、热身方案

### 通用（10-15 min）

1. 5 min 轻度有氧（跑步机快走、划船机、动感单车）
2. 动态拉伸与激活：肩绕环、肩胛俯卧撑、猫牛式、髋屈肌动态拉伸、踝背屈靠墙
3. 空杆 / 轻重量激活组

### 主项递增热身

| 强度 | 组 |
|---|---|
| 空杆 20 kg | ×10 |
| 50% 1RM | ×5 |
| 60% | ×3 |
| 70% | ×2 |
| 80% | ×1 |
| 85% | ×1（>70% 后组间休息 2-3 min） |

### 测试 1RM 的完整流程

热身同上，第一次试举 92-95% 估算值，第二次 97-100%，第三次（可选）101-105%。**最多三次极限单举**，组间休息 3-5 min。

## 三、常见伤痛识别

| 部位 | 常见问题 | 典型表现 | 处理 |
|---|---|---|---|
| 肩 | 肩袖肌腱病 / 肩峰撞击 | 卧推或推举时肩前侧痛、过头动作痛、夜间侧卧痛 | 暂停引发疼痛的动作 1-2 周；改练无痛范围内的动作；加强肩袖与肩胛稳定；持续 >2 周就医 |
| 肩 | 肱二头肌长头肌腱 | 肩前侧深部酸痛，屈肘抗阻加重 | 减负荷，避免过顶与宽握 |
| 肘 | 肱骨外上髁炎（网球肘）/ 内上髁炎 | 握物、反手/正手用力时肘外侧或内侧痛 | 减容量，离心训练（如 Tyler Twist），避免触发动作 |
| 肘 | 卧推时的肘部疼痛 | 底部锁肘或推起时痛 | 检查握距与肘角，减重，护肘不作为主要手段 |
| 腕 | 腕关节过度背伸劳损 | 卧推时腕痛 | 杠压掌根，护腕，必要时改用哑铃/中立握 |
| 膝 | 髌腱病 | 髌骨下方痛，深蹲、跳跃、下楼加重 | 减跳跃与深度，等长收缩训练（分腿靠墙静蹲），渐进负荷 |
| 膝 | 髌股疼痛 | 膝前弥漫痛，久坐后起立加重 | 加强臀中肌与股四头肌，检查膝内扣 |
| 下背 | 腰部肌肉拉伤 | 弯腰/硬拉后局限酸痛 | 短期减负荷，逐步恢复；警惕放射痛 |
| 下背 | 腰椎间盘相关 | **放射到腿的痛、麻木、咳嗽加重** | **立即停止负重，就医**——这是红旗 |

### 处理原则：PEACE & LOVE（2019 BJSM，替代旧 RICE）

| 阶段 | 内容 |
|---|---|
| **P**rotection | 伤后 1-3 天减少负荷与过度活动 |
| **E**levation | 抬高患处（适用时） |
| **A**void anti-inflammatories | 避免长期使用抗炎药——炎症是修复信号的一部分 |
| **C**ompress | 加压/贴扎（减轻水肿） |
| **E**ducate | 理解伤情，避免不必要影像检查与被动治疗依赖 |
| 之后 | |
| **L**oad | 在无痛范围内**逐步加载**——组织需要负荷才能重塑 |
| **O**ptimism | 心理预期影响恢复 |
| **V**ascularisation | 无痛的有氧训练促进血流 |
| **E**xercise | 恢复活动度、力量与本体感觉 |

关键转变：不是完全休息，而是**在可控范围内加载**。完全不动反而延缓肌腱与韧带的重塑。

### 红旗症状（立即就医）

- 放射到肢体的疼痛、麻木、刺痛
- 突发无力或关节活动度丧失
- 夜间痛醒、休息痛
- 肿胀、淤青、可见畸形
- 疼痛 >48 h 不缓解且进行性加重
- 鞍区麻木、大小便功能障碍（马尾综合征，急诊）

## 四、训练量突增的风险

- 单次大幅增加组数或重量是肌腱病最常见的诱因
- 周容量增幅建议不超过 10-20%
- 换动作（尤其不熟悉的动作）时要降重量找感觉，不要沿用旧重量
- 减脂期恢复能力下降，容量突增的风险更高
